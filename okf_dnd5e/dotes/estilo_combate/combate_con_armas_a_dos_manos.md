# Combate Con Armas A Dos Manos

*Dote de estilo de combate (requisitos: rasgo Estilo de combate)*

Cuando tires el daño para un ataque hecho con un 
arma cuerpo a cuerpo que empuñas con ambas manos, 
puedes tratar cualquier 1 o 2 en los dados de daño como 
un 3. Para obtener este beneficio, el arma debe poseer 
la propiedad “a dos manos” o “versátil”.
